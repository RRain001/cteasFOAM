# M1C-19 — face-local native MULES conservative correction (experimental)

Parent Draft PR #46 head cd3744308062bc8d863d3a61ff8c2106998ea408. Pre-implementation acceptance was frozen at a514bbc44684dde81373a6f72433c964bafd0e96. This stage is numerically scoped; do not confuse it with validated URANS, HT/HTO field deposition, soil/interface physics, or external science.

## Method

The opt-in activityConvectionBlend faceMules leaves legacy "none", the M1C-18 globalPositive prototype, and unchanged upwind transport separately executable. Each isotope has **one** native implicit low-order Euler solve using Gauss upwind, source and HT↔HTO reaction, radioactive decay and diffusion. The source for HTO references the **already face-corrected HT**. The additional signed face flux is computed on the low solution from OpenFOAM's native limitedLinear 1 versus upwind advective interpolation. The OpenFOAM v2606 MULES::limiter sees a temporary low-state field whose oldTime equals that low state, zero background correction flux, zero extra reaction/source (both were already included in the implicit solve), a cellwise minimum 0, and a finite upper bound. The resulting synchronized **per-face** lambda limits the correction before subtracting dt*fvc::div(correction) from actual cell concentrations.

The physical signed budget uses **low-order FV matrix face flux frozen before concentration correction**, then adds exactly the signed MULES-limited correction face flux. This freeze is required on physical open boundaries: recovering the matrix flux only after changing the concentration field recalculates a different flux and breaks the Bq balance. No clipping, global reweighting, source retuning, or forced inventory compensation occurs. Physical inlet/outlet/wall patch corrections are exactly zero in this first implementation, retaining the low-order physical boundary flux; processor/cyclic coupled patches participate through OpenFOAM's face sync. This is a real facewise conservative numerical correction, **not** a proof of unconditional boundedness under all flow/mesh/reaction conditions.

## Genuine early native official-v2606 evidence

Three true warped periodic Gaussian plume cases (8³, 16³, 24³), nonzero prescribed U, 80 steps of 0.005 s, frozen source 3840 Bq HT and 768 Bq HTO, and physical Green-function fixed R1/R2/R3 references pass with nonnegative native HT/HTO cells. Maximum signed HT/HTO/total budget residual (Bq) for facewise mode: 8³ 8.97011886991e-9, 16³ 6.93195278956e-9, 24³ 1.25560264408e-8; all far below frozen 1e-5 Bq. 24³ R2 relative error is 0.112646922948 (HT) and 0.0771343209671 (HTO), compared with upwind 0.330709361917 and 0.275031432628. Limiter logs record both isotopes' 80 native per-face coefficient distributions; the minimum lambda of 0 can include inactive zero-correction faces, so do not interpret that minimum as the fraction of actively modified physical flux.

Actual two-rank decomposed 8³ periodic OpenFOAM case reconstructed with maximum HT difference 8.54789959703e-7 Bq/m³ and HTO 5.40039497565e-7 Bq/m³ compared with serial. All 80 native time-step integrated Bq inventories agree within the frozen 1e-5 Bq tolerance; reconstruction and processor boundary exchange are genuine, not mocked.

A real 960-cell nonperiodic duct with positive 0.2 m/s x inlet/outlet and source-free inletOutlet HT/HTO was run for 20 steps. The first run **failed** the native signed open-boundary Bq budget despite nonnegative species, with HT residual ~20 Bq and HTO ~10 Bq, because low-order matrix flux was re-evaluated after the explicit face correction. The corrected implementation stores each low FV flux before state modification and independently checks real xMin/xMax boundary exchange, HT, HTO and combined budgets without loosening the 1e-5 Bq acceptance. The initial failure is retained in Ubuntu reports/m1c19/open-dev1.log; successful post-fix native evidence was captured separately in open-dev2.log. A genuine physical inlet flux reached roughly -345100 Bq/s; the difference between upwind and facewise spatial fields is nonzero, with unchanged boundary inputs.
