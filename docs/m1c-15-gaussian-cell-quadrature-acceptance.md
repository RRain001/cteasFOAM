## Engineering change, physical definition

The established `sourceShape gaussian` distribution currently samples `exp(-|Ccell-center−Csource|²/(2 sigma²))` and multiplies by native cell volume. Add optional **`sourceSpatialQuadrature cellTet4`**, default `cellCentre` for exact backward numerical compatibility. `cellTet4` must integrate the Gaussian density *over each actual warped native polyhedral cell*, using decomposition into tetrahedra from the cell volume centre, face centre, and each face-edge pair, with a 4-point positive symmetric degree-2 tetra quadrature. The source support is stationary and all cells use true native mesh points/faces/face-centres; never silently approximate deformed cells by axis-aligned cubes. The option must be permitted only for configured Gaussian HT/HTO emissions; unknown methods, orphan option, or unsupported source mode fail before any solver timestep. A diagnostic `writeSourceProfile true` switch emits native dimensionless `0/sourceProfile` on explicit request only; default remains unchanged. Source profile is global-volume-normalized by `Foam::gSum(mesh.V()*profile)` in serial/MPI and multiplied by exact overlap Bq/s. Preserve all old field/flux logs and previous 15 scripts unchanged.

For a tetra with centroid/vertices A,B,C,D, quadrature barycentric nodes are permutations of (a,b,b,b), `a=(5+3*sqrt(5))/20≈0.5854101966249685`, `b=(5-sqrt(5))/20≈0.1381966011250105`; equal 1/4 tetra weights, volume `abs(dot(B-A,cross(C-A,D-A)))/6`. Reject nonfinite kernel, zero local support/weight, degenerate/inverted geometry, or tetra summed cell volume differing from actual `mesh.V()` by >0.5% without silent fallback. Do not change HT/HTO transport matrices, coefficients, source rates/windows or actual physical parameters.
