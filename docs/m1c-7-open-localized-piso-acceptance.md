# M1C-7: localized timed HT/HTO emissions in genuine warped 3-D pressure-open PISO flow

**Predeclared before new implementation/tests.** Parent is M1C-6 Draft PR #34 at `6b858f0ec6afceac8cf17eb7be108add3d7963fe`. This milestone is an **end-to-end integration verification** of already prototyped native components; it is not atmospheric URANS, resolved chimney rise, externally validated wind, deposition, or air-soil transfer. No requirement to modify solver PDE coefficients or change earlier thresholds.

## Frozen governing setup

- Official pinned OpenCFD v2606, `cteasAtmosphereFoam` native C++ finite-volume laminar PISO `momentumMode pisoLaminar` with actual 3-D **warped** (665 moved interior vertices), 960-cell unit-box duct; `p(xMin)=+0.1`, `p(xMax)=0` kinematic m²/s², no-slip four side walls, `nu=0.05 m²/s`. 20 Euler steps `dt=0.02 s` to 0.4 s; three pressure correctors and two nonorthogonal corrections (180 native pressure linear solves).
- HT/HTO activity **zero initial and zero external inlet activity** on BOTH x patches (`inletOutlet` with `inletValue uniform 0`), zero-gradient side walls. Thus any internal HT/HTO activity must originate only from localized source, not external inflow. `kOx=0.4 s⁻¹`, **synthetic test decay** `lambdaT=0.2 s⁻¹`, `DHT=0.01` and `DHTO=0.02 m²/s`. `fluxRequired HT/HTO`, `auditActivityFlux=true` for native signed boundary fluxes.
- `sourceShape=gaussian`, `sourceCenter=(0.38,0.62,0.55) m`, `sourceSigma=0.13 m`, `sourceHT_Bq_s=60000 Bq/s`, `sourceHTO_Bq_s=12000 Bq/s`, window `[0.075,0.225) s`. Every real step injects `q*overlap`, not q at a sampled time. Total emitted activity exactly 9000 Bq HT and 1800 Bq HTO over 0.4 s. Native cell weights are MPI-reduced and volume normalized, as frozen in M1C-6.

## Acceptance gates, unchanged for this branch

1. Fresh independent run: native `blockMesh`, explicit 665-vertex interior warp, `checkMesh Mesh OK`, `postProcess writeCellCentres/writeCellVolumes`, full prescribed pressure and source configuration, **20 native HT/HTO and 180 p solves**, complete signed HT/HTO flux, inventory, emitted-activity and flow/divergence logs, and native final `0.4/U`, `0.4/HT`, `0.4/HTO` fields.
2. Independent checker recomputes **each of the 20 discrete Bq activity budgets** from actual logged inventories, signed boundary species flux and injected activity independently calculated from input rates/time windows. Absolute HT, HTO and total residual each ≤**1e-4 Bq**; native logged residual agrees independently to ≤**1e-4 Bq**. Each species final native volume-integral vs the log ≤**1e-4 Bq**. Pressure continuity: each step `|pressure_inlet_flux+pressure_outlet_flux|`, `|boundary_net_flux|`, `|max_div_phi|` ≤**1e-7 m³/s**. Positive x flow both inlet and outlet physical magnitude ≥**0.003 m³/s**, and nonzero 3-D velocity inside; positive final HT and HTO inventories, no negative cells below -1e-5 Bq/m³, actual downstream receptor positive.
3. Independently reconstruct both 960-cell source positions/volumes and verify normalized kernel (finite W>0, nonuniform ratio>1.5, source centroid within 0.15 m target). Independently verify all 20 emission-log values against analytic step overlaps (≤**1e-9 Bq**) and final integrated emitted activity within **1e-9 Bq** of 9000/1800 Bq. For release case, pressure in/out activity BC are zero, while the rate of species outward boundary transport is allowed signed; no assumption that a pressure-open boundary has zero flux.
4. Exact same case/inputs on **genuine two-rank decomposed MPI**, native `decomposePar`, `mpirun -np 2`, `reconstructPar`. Each native reconstructed field and processor mesh must exist. **Serial/MPI field parity** ≤HT L∞100 Bq/m³ and RMS30 Bq/m³; HTO L∞20, RMS6 Bq/m³; U L∞0.003 m/s; all 20 inventories ≤20 Bq, species signed fluxes ≤25 Bq/s, flow volume fluxes ≤1e-6 m³/s. These are same or tighter than frozen M1C-4 limits. Both serial and MPI must independently satisfy source-inclusive budgets in gate 2 and true Bq injection gate 3.
5. **Source-disabled control under exactly the same PISO pressure setup**, with `sourceHT_Bq_s=0`, `sourceHTO_Bq_s=0`; HT/HTO final cells, 20 inventories, species boundary flux, logged injected source ≤1e-8 (in respective native units); native U parity vs emission-active PISO run ≤0.003 m/s. This is an explicit negative control for hidden spurious activity or two-way species→momentum feedback.
6. Tamper each actual native final HT field by +1000 Bq/m³ and one actual emitted HT log record by +1000 Bq; independent checker must fail both. **No** change to any M1C-0..6 source, thresholds or test fixtures to obtain PASS. Exact committed SHA must pass existing seven targeted runners, new runner and seven-step managed Ubuntu Docker `full`. Scientific independence/field validation remains NOT_RUN and GitHub PR Draft.

## Limits

There is **no concentration grid-convergence claim** until at least three controlled mesh resolutions/temporal refinements with fixed physical source sigma and receptor comparisons are separately audited. The pressure-driven flow is laminar PISO, not meteorological URANS and not a buoyant jet, and lambdaT=0.2 s⁻¹ is purely synthetic numerical decay (not tritium physical half-life). This benchmark proves integration numerical bookkeeping and partition consistency only.
