# M1B-1g-12: original icoFoam periodic PISO parity (PRE-RUN)

**Acceptance frozen before the first numerical run.** This increment uses the unmodified official OpenCFD v2606 `icoFoam` executable to check the M1B-1g-11 experimental PISO velocity/pressure path on an **unforced** 3-D warped periodic mesh. Original icoFoam has no `drivingAcceleration` term: the 1g-11 *accelerated* momentum equation is NOT independently reproduced here. This is a genuinely identical-input unforced limit, not an upstream accelerated-flow or HT/HTO validation.

- Generate the same two physical unit-cube meshes (8×20×6=960 and 12×30×9=3240 cells), with x cyclic, y/z physical slip walls, and interior x warp amplitude 0.04; require genuine `blockMesh`, `checkMesh Mesh OK`, and 1–65° non-orthogonality.
- Both applications use identical mesh, `0/U`, `0/p`, `0/c`, `constant/transportProperties`, `fvSchemes` and `fvSolution`. Only `controlDict application` differs. `U(0)=(0.25,0,0)` m/s, `p(0)=0`, no body force, `nu=0.05` m²/s, 3 PISO correctors and 2 inner non-orthogonal corrections. Both run 40 Euler steps of 0.01 s, with final time 0.4 s. The official reference does not solve scalar `c`.
- Require 40 completed timesteps and 360 pressure solves in each application; original final `U` and experimental final `U` must both be within 2e-5 m/s of uniform (0.25,0,0). Each final pressure range must be <=2e-5 m²/s². Original/native final field parity: componentwise U Linf <=2e-5 m/s, pressure **gauge-aligned** Linf <=2e-5 m²/s². Native `max_div_phi` <=1e-8 s^-1, net boundary flux <=1e-8 m³/s.
- Native scalar uses D=0.01 m²/s, initially `c=0.5+0.25cos(2πx)` at genuine cell centres, with upwind advection, leastSquares gradients and corrected diffusion. Its continuum reference is `c(x,t)=0.5+0.25 exp(-D(2π)²t) cos(2π(x-0.25t))`. Final coarse Linf <=0.055, RMS <=0.040; fine Linf <=0.040, RMS <=0.030; fine/coarse RMS ratio <=0.85. These are consistency bounds, not a formal convergence order.
- Require 40 native discrete scalar matrix-flux budgets, each |inventory_new-inventory_old+dt*net_boundary_flux| <=2e-6 m³, |logged residual| <=1e-7 m³, net cyclic flux <=1e-8 m³/s and nonzero signed cyclic through-flux after step 1. This scalar integral is m³, **not Bq**.
- Two negative controls: perturb one original `U` cell by +0.02 m/s and separately one native `c` cell by +0.08. Each must fail for the expected independent criterion. Preserve failure diagnostics.
- Previous 1g-7 through 1g-11, existing official fixed-pressure icoFoam cross-solver, exact-SHA Ubuntu Docker smoke/full, GitHub admission and independent non-bot scientific review remain separate gates. No URANS, HT/HTO, soil or air–soil coupling claim; keep Draft/unmerged until required science gates pass.
