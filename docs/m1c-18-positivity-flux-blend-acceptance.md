# M1C-18 — global conservative high-order flux-blending prototype (frozen before implementation)

Parent M1C-17 Draft PR #45 exact SHA `13efcd2569260e3336bcbae934aa6fc548e0ab7a`. This is a deliberately limited first mathematical baseline toward local FCT/MULES. It is **NOT a completed face-local FCT/MULES method**. Its purpose is to establish a high/low conservative pair and reject unsafe concentrations without clamping.

Physical/numerical contract:

1. Add opt-in `activityConvectionBlend globalPositive` under `activityMode htHto` on genuinely periodic, prescribed-U, single-rank three-dimensional meshes ONLY; default `none` preserves every previous benchmark and default `Gauss upwind` behavior. Unsupported modes, MPI and nonperiodic patches fail closed. `div(phi,HT)` and `div(phi,HTO)` remain `Gauss upwind`, additional named `div(phi,HTHigh)` and `div(phi,HTOHigh)` select only `Gauss limitedLinear 1` (not source/physics changes).
2. For each species solve two actual OpenFOAM conservative finite-volume Euler matrices with identical old-time field, source, implicit reaction and diffusion: low-order upwind, candidate high-order limitedLinear. HT first; HTO source references the *final* blended HT. For each species find one deterministic global alpha in [0,1] that ensures every blended cell concentration `(1-alpha)*low+alpha*high >= 0` when low is already nonnegative. This preserves each species global inventory as the same convex combination of actual FV solutions (no post-hoc clipping, no rescaling). Low negative/nonfinite, high nonfinite, or no admissible alpha is a hard failure. Optional `enforceNonnegativeActivity true` remains compatible.
3. The exact same convex alpha MUST blend the low/high species equation signed native face-flux fields, so the existing HT/HTO/total activity budget check is valid with old state, source overlap, identical kOx/lambdaT and actual combined fluxes. The FVM total tritium activity and separate HT→HTO conversion must agree at each timestep within existing `1e-5 Bq` tolerance. Alpha is per species (not per cell), so this is intentionally a **global** limiter and can be over-diffusive: do not claim a locally optimized FCT/MULES scheme.
4. Use existing true warped 8³/16³ (and when feasible 24³) periodic Gaussian pulse benchmark, dt .005 s to t .4 s; source HT 3840 Bq/HTO 768 Bq, native U, spatial moments, fixed physical R1/R2/R3 independent Green reference identical to M1C-16. Verify 80 genuine steps; native 80-step extrema nonnegative; no missing/NaN alpha, zero/negative tamper rejection; unchanged conservative budgets; compare R2 errors to upwind and rejected limitedLinear without predeclared improvement. Run a 2-rank rejection test for unsupported MPI, a wrong named scheme rejection test and a nonperiodic boundary rejection.
5. Retain all 18 previous M1C-0..17 targeted suites and exact SHA Ubuntu Docker full. No auto-merge/science label without independent field validation/review. URANS, soil and air-soil interface remain unimplemented.

This stage is explicitly exploratory: if the positivity alpha collapses near 0 in long-tail cells, record it honestly as a negative accuracy finding and proceed to a local conservative facewise FCT/MULES rather than weakening positivity or budget gates.
