This is an **idealized volumetric spatial kernel** for testing local injection and source-grid independence, not a physically modeled chimney plume, momentum/buoyancy injection, URANS or a validated atmospheric release.

## Exact governing contract

M1C-5 finite-window rates `sourceHT_Bq_s` and `sourceHTO_Bq_s` retain dimensions [0 0 -2 0 0 0 0] = Bq/s. Existing `sourceStart/sourceEnd` and exact per-Euler-step overlap are unchanged. New `sourceShape uniform|gaussian`, default uniform, is legal **only when emission rates are configured**. For `gaussian`, require `sourceCenter` dimensionedVector [0 1 0 0 0 0 0] in m, and `sourceSigma` positive dimensionedScalar [0 1 0 0 0 0 0] in m. Reject missing, wrong dimensions, nonfinite center/sigma, sigma<=0, unsupported shape and sources whose all local/global weights underflow to zero. No silent fallback. Do not assume `sourceCenter` is a stack source or prescribe release height physics.

On each native cell i at center x_i and native positive volume V_i, compute `w_i = exp(-|x_i-center|²/(2 sigma²))`; `W = MPI_global_sum(V_i w_i)`. The **scalar Bq/m³/s source density** is `s_i=Q(t) w_i/W`; Q(t) = Q_Bq_s × (overlapSeconds/deltaT). This guarantees `sum_i V_i s_i deltaT = Q_Bq_s overlapSeconds` over the actual discretized physical mesh and all ranks. With uniform mode preserve exactly M1C-5 `Q / MPI_global_sum(V)`. Both HT and HTO have same optional spatial shape and independently specified rates, no mixing of species/units. The already frozen source-inclusive HT/HTO/total Bq and boundary-flux budgets must remain unchanged. All prior cases without `sourceShape` retain their original output.
