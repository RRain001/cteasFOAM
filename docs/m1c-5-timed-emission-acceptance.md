## Equation, units and operator

Activity concentration `HT,HTO`: [0 -3 -1 0 0 0 0] (Bq/m³); integrated domain inventory A [0 0 -1 0 0 0 0] (Bq); emission rates `sourceHT_Bq_s` and `sourceHTO_Bq_s`: [0 0 -2 0 0 0 0] (Bq/s). Optional source keys are read **only in `activityMode htHto`**. A nonzero emission requires explicitly dimensioned `sourceStart`, `sourceEnd` in seconds [0 0 1 0 0 0 0]; no implicit schedule or negative emission rate. On each Euler time step [t_old, t_new], inject integrated activity `Q * overlap([t_old,t_new],[start,end])` rather than sampling start/mid/end values. The source density (Bq/m³/s) is Q divided by the total **globally reduced** mesh volume, uniformly over all cells. The emission schedule [start,end) is finite, and no injection occurs after the end. An invalid source dimension, negative rate, absent schedule, or end≤start must explicitly fail before stepping. Without source keys every earlier M1C run must be unchanged.

Discretely, at each time level, `A_HT,n-A_HT,n−1 + Δt F_HT,n + Δt(kOx+λ)A_HT,n - Q_HT Δt f_n = 0`, `A_HTO,n-A_HTO,n−1 + Δt F_HTO,n + Δt λ A_HTO,n - Δt kOx A_HT,n - Q_HTO Δt f_n = 0` and total `A_n-A_n−1 + Δt(F_HT+F_HTO) + Δt λ A_n - (Q_HT+Q_HTO) Δt f_n = 0`. `f_n` is exact fractional overlap. The independent checker derives injected activity from **input configuration and times**, not the emitted log alone. Both flux audit and closed-box budgets must include the source amounts, and must not conflate emitted flux with outward boundary flux.
